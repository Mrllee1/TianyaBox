## 剧场问题的复现和原因

修复前，在原生预览加载真实公开剧场列表后，点击顶部“推荐”，剧场“更多”按钮仍存在，回归测试失败。控件树中，剧场装饰封面的区域为 `{{10.0, -33.7}, {420.0, 933.3}}`，越过顶部分类按钮所在的 y=73…101 区域。

原实现只做视觉裁剪，没有约束封面的点击区域；SwiftUI 的 `.clipped()` 不会自动把命中区域限制到可见边界。因此图像仍可拦截上方按钮的点按。

- 给剧场卡片明确的可用高度，限制整体边界；装饰封面、渐变和指示器不参与命中。
- 给共享远程图像添加边界内的 `contentShape`；首页内容和公共二级页也约束命中边界，标题栏与底部导航保持在上层。
- 顶部分类最小点击高度 44，底部导航整格 64 可点击。保留原版图标和视觉方向。
- 在真实公开剧场内容及测试数据两种路径回归；顶部四分类往返、底部导航、会员页进入/返回均通过。
