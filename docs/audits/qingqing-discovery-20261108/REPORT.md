# 发现页自动分页与推荐空态恢复 R8（2026-11-08）

发现页“热门标签”的角色网格改为滚动接近底部自动续页，正常浏览无需点击“加载更多”。B 面未改，VIP / 钻石的 R7 套餐兼容逻辑保留。

## 改动

- 根据真实滚动位置和内容高度，在距底部约 200 点时请求下一页。加载中显示进度，失败保留已加载内容，只在失败时显示“重试加载更多”；失败不会自动循环重试。
- 继续沿用分类、请求代次、加载状态和连续页码校验，阻止重复或跨分类翻页。返回不足 20 条，或整页未新增任何角色时停止；到底显示“已经到底了”。切换分类 / 排行时列表回到顶部，分页追加保留当前滚动位置。
- 推荐等首页分区成功返回空列表时，不再缓存为本次运行永久完成；切回分区可重试，空态增加“重新加载”。不填入合成角色或把发现页角色冒充推荐结果。
- 设备状态日志仅增加公开列表条数、页码和响应形状，不保存角色正文、账号信息、查询词或凭据。
